# A Love Letter In The Stars ✨

A romantic, interactive web experience crafted with love.

## 💖 Features
- **Interactive Wax-Seal Envelope Intro**: 3D envelope that breaks open with heart particle fireworks.
- **Live Love Counter**: Real-time counter of days, hours, minutes, and seconds together.
- **Interactive Starfield & Floating Hearts Canvas**: Dynamic starry sky and floating hearts that react to clicks.
- **3D Tilt Polaroid Scrapbook**: Interactive memory cards with realistic 3D hover physics.
- **"Reasons Why I Love You" Card Deck**: Interactive deck to flip through heartfelt reasons.
- **Digital Love Letter**: Vintage styled romantic letter.
- **Playful Surprise Section**: Interactive "Yes" celebration & runaway "No" button.
- **Ambient Romantic Music**: Built-in soothing melody engine powered by Web Audio API.
